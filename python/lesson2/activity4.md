# 활동 4 - 통로 만들기

```python
blocks.place(PLANKS_OAK, pos(0, 0, 0))
```

## 1단계

바닥에 생긴 구멍을 건널 수 있도록 파이썬 코드로 통로를 만드세요.

금 블록 다음 위치부터 알맞은 블록을 하나씩 배치하세요.

`||blocks: place block at position||` 명령어를 사용하여 블록의 종류(PLANKS_OAK)와 상대 좌표를 변경하세요.

높이는 일정하게 유지하고 이동 방향의 좌표를 변경하면서 블록을 연속으로 배치하세요.

통로를 완성한 후 반대편으로 건너가세요.

### ~ tutorialhint

상대 좌표의 기본 구조는 `pos(x, y, z)`입니다.

- X : 동쪽(+), 서쪽(-)
- Y : 위쪽(+), 아래쪽(-)
- Z : 남쪽(+), 북쪽(-)

평평한 통로를 만들려면 Y축 좌표를 일정하게 유지하세요.

블록을 잘못 배치했다면 NPC와 대화한 후 **다시 도전** 버튼을 누르세요.
