# 활동 2 - 조명 설치하기

```python
blocks.place(REDSTONE_LAMP, pos(0, 0, 0))
```

## 1단계

서로 다른 높이에 레드스톤 램프 3개를 설치하세요.

`||blocks: place block at position||` 명령어를 사용하여 지정된 위치에 레드스톤 램프(REDSTONE_LAMP)를 배치하세요.

플레이어의 위치를 기준으로 Y축 좌표를 변경하면 서로 다른 높이에 블록을 배치할 수 있습니다.

모든 램프를 올바르게 설치한 후 레버를 작동하여 조명을 켜세요.

### ~ tutorialhint

상대 좌표의 기본 구조는 `pos(x, y, z)`입니다.

- X : 동쪽(+), 서쪽(-)
- Y : 위쪽(+), 아래쪽(-)
- Z : 남쪽(+), 북쪽(-)

블록을 잘못 배치했다면 NPC와 대화한 후 **다시 도전** 버튼을 누르세요.
