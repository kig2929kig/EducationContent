# 활동 1 - 블록 배치하기

```python
blocks.place(GRASS, pos(0, 0, 0))
```

## 1단계

지정된 위치에 알맞은 블록을 배치하세요.

- 잔디 위에는 잔디 블록을 배치하세요.
- 벽돌 위에는 벽돌 블록을 배치하세요.

**블록 배치 명령어**

`blocks.place(GRASS, pos(0, 0, 0))`

**명령어 구성**

- `blocks.place()` : 블록 배치 함수
- `GRASS` : 블록 종류
- `pos(x, y, z)` : 상대 좌표

**좌표의 의미**

- X : 동쪽(+), 서쪽(-)
- Y : 위쪽(+), 아래쪽(-)
- Z : 남쪽(+), 북쪽(-)

블록 종류와 좌표를 알맞게 변경하여 코드를 실행하세요.
