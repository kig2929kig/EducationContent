### ~ tutorialhint

블록을 배치하는 기본 명령어는 다음과 같습니다.

```python
blocks.place(GRASS, pos(0, 0, 0))
```

- `blocks.place()` : 블록을 배치하는 함수
- `GRASS` : 배치할 블록의 종류
- `pos(0, 0, 0)` : 플레이어를 기준으로 한 상대 좌표

좌표는 X, Y, Z 순서로 입력합니다.

배치할 블록의 종류와 좌표를 알맞게 변경하여 실행하세요.
